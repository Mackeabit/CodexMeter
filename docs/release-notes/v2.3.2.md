## 변경 내용 (Dual)

- **5시간 우선 숫자**: 링 가운데 숫자는 5시간 한도가 남아 있으면 5시간 값을, 5시간 한도가 없거나 다 쓰면 주간 값을 보여 줍니다. 링 순서도 바뀌어 **바깥 링이 주간, 안쪽 링이 5시간**입니다.
- **어느 한도인지 표시**: 상세 창, "작게" 보기, 작업표시줄 모두 가운데 숫자에 해당하는 한도를 표시합니다. 상세 창과 작업표시줄에서는 그 줄 앞에 서비스 색 점과 옅은 배경이 붙습니다.
- **작업표시줄 두 줄 표시**: 트레이 옆에 자리가 있으면 링 옆에 `5h`·`주` 두 줄(남은 양, 자리가 넉넉하면 리셋까지 시간)을 보여 줍니다. 자리가 좁으면 예전처럼 짧게 표시합니다. 미터는 항상 트레이 옆에 머뭅니다.
- **사용 불가 표시**: 어느 한도든 0%가 되면 빨간 "사용 불가"와 다시 쓸 수 있을 때까지 남은 시간을 보여 주고, 트레이 숫자도 빨간색이 됩니다. 리셋 시각이 지난 0% 값은 사용 불가로 보지 않습니다.
- **5시간 한도가 없는 계정**: Codex가 주간 한도만 보내면 "없음 · 주간 한도만 있음"으로 표시하고 안쪽 링을 그리지 않습니다. 값을 확인하지 못한 경우(`—`)와 구분됩니다.
- **Claude 잔여량 알림**: Codex와 같은 규칙으로 20% 미만, 5% 미만일 때 한 번씩 알립니다(제목 "Claude 잔여량 …"). 알림 켜기/끄기와 "다음 리셋까지 알림 끄기"는 두 서비스에 함께 적용됩니다. 오래된 Claude 값으로는 알리지 않습니다.
- **방해 금지 중 알림 보류**: 방해 금지(전체 화면 앱을 쓸 때 자동으로 켜지는 경우 포함), 프레젠테이션, 잠금 화면처럼 Windows가 알림을 받지 않는 동안에는 알림을 버리지 않고 기다렸다가 표시합니다.
- **"작게" 보기**: Codex만 보이던 작은 창이 Codex와 Claude를 나란히 보여 줍니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다. 알림을 받으려면 트레이 메뉴에서 **잔여량 20%·5% 알림**을 켜세요.
