# CodexMeter v2.3.3 · Dual 작업표시줄 표시 보완

## 변경 내용 (Dual)

- **줄임말 없는 표시**: 작업표시줄 링 옆 두 줄이 `5h`·`주` 대신 `5시간`·`주간`으로 표시됩니다.
- **남은 시간 항상 표시**: 각 줄에 리셋까지 남은 시간을 "6일 13시간", "4시간 17분"처럼 보여 줍니다. 다 쓴 한도는 다시 쓸 수 있을 때까지 남은 시간("2시간 0분 후")을 빨간색으로 표시합니다.
- **자리 찾기**: 이 표시는 150%에서 약 590px가 필요합니다. 트레이 옆에 자리가 없으면 작업표시줄에서 이 표시가 들어가는 가장 가까운 빈자리로 옮겨 갑니다. 시간이 빠진 중간 표시는 없앴고, 작업표시줄 어디에도 자리가 없을 때만 짧은 표시(`5시간`/`주간`과 짧은 시간)로 바뀝니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다.
