# CodexMeter v2.3.4 · 낮은 작업표시줄에서도 두 줄 표시

**Dual** 작업표시줄의 두 줄 표시(`5시간`·`주간`, 남은 양, 리셋까지 남은 시간)가 높이 40px(100% 배율) 작업표시줄에서도 나오도록 고쳤습니다. Classic과 Expanded는 바뀌지 않았습니다.

여섯 파일 모두 Windows x64용이며 **.NET 10 실행환경을 포함**합니다. 원하는 디자인 하나를 선택하세요.

## 변경 내용 (Dual)

- **낮은 작업표시줄 지원**: 두 줄 표시는 높이가 34 DIP면 충분한데, 지금까지는 40 DIP 이상일 때만 썼습니다. 그래서 높이 40px 작업표시줄(100% 배율, 미터에 쓸 수 있는 높이 36 DIP)에서는 짧은 표시로 바뀌었습니다. 이제 이런 작업표시줄에서도 두 줄과 남은 시간이 모두 나옵니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다.

## 검증

- [Windows CI 빌드 및 검증]({{RUN_URL}})에서 생성하고 설치·업데이트·제거 검사를 통과한 파일을 배포합니다.
- 자동 검사: Classic 146개, Expanded 148개, Dual 215개. 실제 데스크톱에서 측정한 작업표시줄(1920×40, 100%)에서 두 줄 표시가 선택되고 그려지는지 검사를 추가했습니다.

EXE는 아직 코드 서명이 없습니다. Windows SmartScreen이 경고할 수 있습니다. [SHA256SUMS.txt](https://github.com/Mackeabit/CodexMeter/releases/download/v{{VERSION}}/SHA256SUMS.txt)로 받은 파일의 무결성을 확인할 수 있으며, 해시는 코드 서명을 대신하지 않습니다.
