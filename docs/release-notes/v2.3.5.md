## 변경 내용 (Dual)

- **더 밝은 글자**: 작업표시줄의 `5시간`·`주간`과 남은 시간이 흐린 회색 대신 밝은 색으로 표시됩니다. 어두운 작업표시줄과 밝은 작업표시줄 모두에서 배경 대비가 9:1 이상입니다.
- **더 선명한 글자**: 글자 크기를 11px에서 12px로 키우고, 글자 윤곽을 화면 픽셀에 맞춰 그려 번짐을 줄였습니다.
- **더 큰 링 숫자**: 링 안 숫자가 150% 배율에서 약 12px에서 15px로 커졌습니다. 높이가 낮은 작업표시줄에서도 안쪽 링에 닿지 않게 크기를 맞춥니다. 상세 창의 링 숫자도 함께 커졌습니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다.

## 검증

- [Windows CI 빌드 및 검증]({{RUN_URL}})에서 생성하고 설치·업데이트·제거 검사를 통과한 파일을 배포합니다.
- 자동 검사: Classic 146개, Expanded 148개, Dual 218개. 글자 대비, 링 숫자가 안쪽 링 안에 들어가는지(150% 노트북, 40px 데스크톱 작업표시줄), 늘어난 글자 폭 검사를 추가했습니다.
- Windows 11 x64(150%) 실제 작업표시줄에서 확인했습니다.

EXE는 아직 코드 서명이 없습니다. Windows SmartScreen이 경고할 수 있습니다. [SHA256SUMS.txt](https://github.com/Mackeabit/CodexMeter/releases/download/v{{VERSION}}/SHA256SUMS.txt)로 받은 파일의 무결성을 확인할 수 있으며, 해시는 코드 서명을 대신하지 않습니다.
