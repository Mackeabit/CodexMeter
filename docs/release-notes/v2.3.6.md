## 변경 내용 (Dual)

- **선명한 글자**: 작업표시줄의 `5시간`·`주간`, 남은 시간, 링 숫자를 WPF 글꼴 엔진으로 픽셀 격자에 맞춰 그립니다. 이전에는 100% 배율에서 12px 한글이 흐리게 번져 보였습니다. 작게 보기와 상세 창의 링 숫자도 같은 방식으로 그립니다.
- **링 숫자 여백**: 40px 작업표시줄(100%)에서 링이 28에서 30 DIP로 커지고, 링 숫자는 실제 글자 모양을 재서 안쪽 링과 최소 1픽셀 떨어지게 맞춥니다. 이전에는 `88` 같은 숫자가 안쪽 링에 닿았습니다. 150% 노트북의 링과 숫자 크기는 그대로입니다.
- **Windows 10 숫자 굵기**: Segoe UI Variable이 없는 Windows 10에서는 링 숫자와 퍼센트를 일반 Segoe UI 대신 Segoe UI Semibold로 그려, Windows 11과 같은 굵기로 보입니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다.
