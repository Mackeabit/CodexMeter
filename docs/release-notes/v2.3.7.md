## 변경 내용 (Dual)

- **새 서비스 색상**: Codex는 에메랄드 그린(`#1FAF7E`), Claude는 테라코타 오렌지(`#D97757`)로 표시합니다. 이전에는 Codex가 주황, Claude가 보라였습니다. 작업표시줄 링, 행의 점과 강조 배경, 작게 보기와 상세 창의 링·점·행 배경, 분할 막대에 적용됩니다.
- **읽기 쉬운 강조 글자**: 밝은 작업표시줄과 흰 창의 서비스 색 글자는 같은 색 계열의 진한 톤(`#047857`, `#A4492C`)으로 그려 배경 대비 4.9:1 이상을 유지합니다.
- 20% 미만·사용 불가 표시는 빨강, 오래된 값은 회색으로 이전과 같습니다.

## 업데이트

새 설치 EXE를 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 사용자 설정, 중복 알림 방지 기록, 자동 실행 등록을 유지합니다. 세 디자인은 같은 설치 위치를 사용합니다.
